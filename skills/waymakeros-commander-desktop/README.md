# WaymakerOS Commander Desktop skill

`status: draft`

For agents running in a terminal inside Waymaker Commander Desktop (the Mac app). It covers the
Explorer model (My Workspace / Workspaces / Repositories), what a terminal in a repository linked
to a Commander project tells the agent, `commander open`, secrets, syncing My Vault, the opt-in
Apple Mail tools, and sign-in through Waymaker Companion.

Written against the released Commander Desktop build (0.2.19) — only shipped behaviour. Desktop
changes often; re-verify each section against the current release before publishing an update.

This directory is the canonical source. It is published to the public `waymakeros` skills package.
Load it via the `waymakeros` entry-point skill.
